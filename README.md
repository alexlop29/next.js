### About
Demonstrates a series of simple components to display leveraging global state management with MobX and a REST API

### 🏄 Getting Started
```
nvm use 20.17.0
npm install
npm run dev
```

### 🔧 Core libraries
- [Next.js](https://nextjs.org/)
- [TailwindCSS](https://tailwindcss.com/)
- [MobX](https://mobx.js.org/)
